# Dotes data

| File | What's inside |
| --- | --- |
| [`dotes.json`](dotes.json) | The 63 sample dotes from Melu, Jessi and Cyrus, one object per dote, valid against [`../schema/dote.schema.json`](../schema/dote.schema.json) |
| [`dotes.csv`](dotes.csv) | The same 63 dotes as one table, one row per dote |
| [`categories.json`](categories.json) | The seven categories with their focus, lens question, definition and boundary, and all 35 subcategories with their intents and starter prompts |

The personas, and everyone in their stories, are fictional.

Check any dote file against the schema and the canon with `python tools/validate.py data/dotes.json`.
